# Kassensturz

Gemeinsames Haushaltsbuch für euch beide. Ein Login (oder Beitrittscode), ein Datenstand, zwei Töpfe: **Privat** und **Gewerbe**, oben immer die Summe.

## Wichtig

Die **lebende App** ist die veröffentlichte Kassensturz-PWA (gleiche Adresse auf beiden Handys). Dort liegen die gemeinsamen Zahlen in der App-Datenbank — nicht in diesem Repo.

Dieses Repository ist die **Quell-Notiz**. GitHub Pages kann diese App nicht hosten (sie braucht einen Server + Datenbank).

## So nutzt ihr sie

1. Eine Person registriert sich (Google, X oder E-Mail) und legt den Haushalt an.
2. Die andere tritt mit dem Code unter **Einstellungen** bei — oder ihr teilt euch dasselbe E-Mail-Login.
3. Beide: Browser-Menü → **Zum Home-Bildschirm** (PWA).
4. Konten mit aktuellem Startsaldo füllen, dann buchen.

## Drin

- Gesamtübersicht + Privat / Gewerbe
- Budget-Methode umschaltbar (Limits, Umschläge, 50/30/20, Zero-based)
- Buchungen, Umbuchungen, Fixkosten mit Ampel
- Sparziele, Schulden, Berichte, CSV-Export
- Keine Steuererklärung, kein Elster, kein Bankabruf

Währung: Euro. Sprache: Deutsch.
